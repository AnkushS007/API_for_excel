# AM4 Rapid Growth Assistant

Read-only Chrome extension for Airline Manager 4. Passively captures browser-visible game data and feeds a rapid-growth optimizer.

## Principles
- User logs into AM4 normally.
- No AM4 credentials are handled by the project.
- No automated purchases, sales, route creation, price changes, or other game-changing actions.
- Captured AM4 data stays in browser storage.

## Roadmap
1. Passive AM4 capture
2. Map real AM4 payloads
3. Fleet/route economics
4. Expansion/replacement planner
5. Local "Analyze My Airline" dashboard
